# EDITORS.MoipBuddy — Media over IP (MoIP) Stream Buddy

**Wiki:** [Documentation/README.md](Documentation/README.md) — principles, architecture, delivery.

Media-over-IP (MoIP) Stream Buddy: manage multicast stream assignments, IGMP snooping queriers, SDP session descriptions, SMPTE ST 2110 / ST 2022-7 hitless redundancy, and Dante/AES67 audio flows.

| | |
|---|---|
| **Opens** | the OS shell (Design → Network & Topology), or `index.html` standalone |
| **Build** | none — plain web files; `npm test` |
| **Ships** | baked into WEB.Frontend-Assets (`up-stack.sh WEB.Frontend-Assets`), served at `:8080/Softapps/EDITORS/EDITORS.MoipBuddy/` |
